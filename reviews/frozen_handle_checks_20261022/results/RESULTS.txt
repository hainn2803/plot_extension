2. AP label-copying control

Frozen before inference: 96 original AP-only pairs, eight per ordered transition,
selected by fixed hashes. Each original transposition donor has two three-row
cycle controls. All donors preserve C, natural AT, and source AP, but cycles
make the label at the patched slot disagree with the AP target. We patch the
source/base structural slot selected by the base correct option, at all 26
decoder-block outputs. This site selection is annotation-routed.

All 384 natural prompts and 7,776 interventions were saved. Strict full-vocabulary
scoring counts ties and invalid outputs as failures. Sixty-five original pairs
have correct natural predictions for the base and ALL three donors, leaving
65 transposition and 130 cycle cases. Every transition remains represented,
with 2-8 clean original pairs per transition. All attempted results are also
reported, without replacement or quota refilling.

At each layer 3-15, transposition AP accuracy is 64/65 = 98.46%, but cycle AP
accuracy is 0/130 = 0%. Cycle outputs follow the label-copy prediction in
93.08-96.92% of cases across those layers. The original golden-token success
therefore does not establish an AP handle. It is consistent with changing the
label associated with the base's correct color. This does not establish that
AP is absent elsewhere in the network or that DAS cannot learn it.

Hai's uploaded learned AP handle at block 17/final token/rank 128 behaves
differently: AP accuracy is 31/65 = 47.69% on transpositions and 65/130 = 50.00%
on cycles. Cycle label-copy accuracy is 9/130 = 6.92%. It is not explained by
the same simple golden-slot copying pattern, but remains unreliable here.

3. C preservation and measurement baseline

Both uploaded C handles preserve output and same-base replay on all 739 clean
preservation pairs: 368 AP-only and 371 AT-only. The uploaded AT readout is
84.78% and 86.25% accurate, respectively, both before and after C intervention.
Its predicted classes agree before/after on every case. Those classifier errors
are therefore already present in the clean baseline.

AP-only prompts have identical cached C states. Two AT-only historical cache
entries differ from matched base C states by at most 0.03125. These cases were
retained. A separate 32-pair diagnostic including the largest discrepancies
uses identical fixed padding and physical batch shapes. Source/base C states
then match exactly; both frozen C interventions reproduce clean logits exactly.
This resolves the numerical-layout concern for those cases, while preserving
the old evidence. Invariance here is largely architectural because changed
options occur after the color token; it is a useful sanity check.
